# MilitaryReconSim

Co-author demo of the Study 2 route reconnaissance simulation (multi-UGV supervision).

**Play it:** https://lionelprobertjr.github.io/MilitaryReconSim/

The start page lets you pick a training condition (C1-C4) and where to start (mission only, training then
mission, or the full session). Everything runs in the browser; nothing is recorded or sent anywhere.

This repository holds only the built demo (static files). It is generated from the main project with
`node scripts/demo/build-demo.mjs`; do not edit these files by hand.

Not for participants: the study itself runs on the study server with consent, assignment and data upload.
